# Junkyard Revival

Godot 4 Android landscape vehicle restoration game.

## Development status
Automated Godot validation workflow is configured in [GitHub Actions](../../actions). The game source and artwork have **not yet been committed to this repository**, so the workflow currently reports a notice and skips Godot project validation. A successful workflow at this stage does not mean gameplay has been tested.

## Design principles
- Dedicated scenes for each tab, gritty sunset junkyard artwork.
- Free-form customisation and stripping, including selling every component and bare shells without penalties.
- No energy or stamina restrictions.
- Planned online car shows, server-controlled refreshes, and rare vehicle events.

Never commit signing keys, API secrets, or player data to this public repository.
